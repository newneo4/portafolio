# Iconos Yaru (Ubuntu)

Fuente: https://github.com/ubuntu/yaru (@ sudo `master`, carpeta `icons/`)

Los iconos de este directorio pertenecen al tema de iconos **Yaru**, oficial de Ubuntu,
autoría de Canonical Ltd. / comunidad de Ubuntu.

- **Yaru icon assets** (archivos `.svg` y `.png`): licencia **CC BY-SA 4.0**

Los PNG full color se tomaron del tema renderizado (`icons/Yaru/48x48@2x`, 96px, retina).
Los SVG simbólicos se tomaron de `icons/Yaru/scalable`.
